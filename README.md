# AgroSmart
Sistema Inteligente de Gestión, Análisis y Recomendación Agrícola (CDMX y Zona Metropolitana).

## Instalación rápida
1. Importar el archivo `agrosmart_db.sql` en MySQL.
2. Editar `app.py` con el usuario y contraseña de MySQL local.
3. Instalar dependencias: `pip install flask mysql-connector-python`
4. Ejecutar: `python app.py` y abrir `http://127.0.0.1:5000`
